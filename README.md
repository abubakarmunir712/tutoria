# Tutoria

AI-powered homework tutor for Ghanaian students, grounded in the official NaCCA curriculum (Primary 4–6, JHS 1–3, SHS 1–3). Native Android/iOS app in Flutter.

## Structure

- `app/` — Flutter student app (Android + iOS)
- `server/` — NestJS backend API
- `admin/` — React admin/telemetry dashboard
- `docs/` — project docs
  - `PRD.md` — full product requirements & milestone task checklist
  - `PROJECT_BRIEF.md` — client decisions, status, open items (start here)
  - `sources/` — curriculum source materials from the client/consultant
  - `raw/` — raw client thread log

Each of `app/`, `server/`, `admin/` is its own git repo.
