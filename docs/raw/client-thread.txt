Homework Buddy AI (Tutoria) — Milestone Structure
Build: Native Android and iOS (Flutter)

Milestone 1: Foundation, Design Direction, and Authentication — Weeks 1 to 2
Set up the production Flutter environment for the native Android and iOS targets. Establish the design direction and app flow. Build student registration, login, and profile data layer. Stand up the dashboard scaffold and navigation structure. Ingest and structure the initial curriculum source data ready for the AI pipeline.

Milestone 2: AI Core, Curriculum RAG, and Voice Pipeline — Weeks 3 to 5
Connect the AI tutor to the curriculum through the Qdrant vector database with a Socratic teaching approach. Build homework upload with OCR, cross-referenced against the curriculum. Deploy real-time voice interaction, speech-to-text for student input and text-to-speech for tutor responses. Run a model and cost review to select the production AI configuration.

Milestone 3: Gamification and Dashboard — Weeks 6 to 7
Implement XP scoring and streak tracking with backend persistence. Build the rewards screen and complete the student dashboard. Integrate the admin and telemetry dashboard.

Milestone 4: Native Packaging, Cross-Platform QA, and Launch — Week 8
Package the native Android and iOS builds. Configure native push notifications and store assets. Conduct end-to-end testing across both platforms. Final launch and handover.
